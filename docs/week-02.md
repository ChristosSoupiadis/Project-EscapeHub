# Αναφορά Εβδομάδας 2 - Μέλος Β (Scrum Master)

Αυτή την εβδομάδα ασχολήθηκα με τη δημιουργία και διαχείριση ομάδων μέσω κωδικού πρόσκλησης (`TeamService`), ώστε οι χρήστες να μπορούν να φτιάχνουν ομάδες και να μπαίνουν σε αυτές με ασφάλεια. Παράλληλα, ως Scrum Master της εβδομάδας, βοήθησα με τα issues, τους ελέγχους (reviews) και τις συγχωνεύσεις (merges) στο GitHub ώστε να ολοκληρωθεί το κομμάτι της εβδομάδας.
