## Πώς τρέχει
1. IntelliJ: `File → Open` → ο φάκελος του repo.
2. Δεξί κλικ στο `src` → `Mark Directory as → Sources Root`.
3. Άνοιγμα `src/escapehub/Main.java` → πράσινο ▶.
## Κανόνες
- Κανείς δεν κάνει push στο `main`. Κάθε task: δικό του branch → Pull Request → 1 review → merge.
- Όνομα branch: `w1-<μέλος>-<τι-κάνει>`, π.χ. `w1-b-users`.
- Πριν ξεκινήσεις κάτι νέο: `git pull` στο `main`.
